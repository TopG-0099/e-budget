# agent-plans/

Output of the `/investigate-e-budget` skill lands here, one file per
investigation: `YYYY-MM-DD-<slug>.md`, using the template the skill defines
(Context, Findings, Open Questions, Recommended Approach, Non-goals).

This is a record of _why_ a change was approached a certain way, kept
separate from `mvp-plan.md` and `architecture.md`, which describe the
current intended state rather than the history of how a specific
investigation got there.
