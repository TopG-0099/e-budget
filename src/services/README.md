# services/

One file per Dataverse entity, e.g. `cep.ts`, `cer.ts`. Each file wraps the
CRUD calls for that entity (create/read/update/list, status transitions) and
returns/accepts types from `src/models`.

These will largely be generated by `pac code add-data-source` once a real
Dataverse table exists; hand-written services should follow the same
one-file-per-entity shape.

Do not put React/UI code here — this layer only talks to Dataverse.
